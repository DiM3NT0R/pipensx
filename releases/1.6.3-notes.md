## Release 1.6.3

**In short:** fixes console hangs, aborts/crashes during large downloads and installs, and ensures base games with words like "patch" in their titles (e.g. *Dispatch*) install correctly instead of being marked as duplicate updates.

### Stability & Installs (P0-1, P0-2, P0-3)

- **Fixed install stalling & rate collapse:** downloads no longer grind to 0 B/s behind the install gate due to exponential EMA rate degradation (`e653bf2`).
- **Survive network buffer exhaustion:** Switch BSD socket `ENOBUFS` errors are now handled gracefully without triggering a reconnection storm, and transient piece buffer allocation limits no longer trigger `std::abort` (`4a59aba`).
- **NAND system memory safety margin:** installs to system memory (NAND) now require a 512 MB safety buffer (`kNandSafetyMarginBytes`) to prevent Horizon OS allocation panics and console reboots on low-space EmuNAND partitions.
- **Base game title classification:** game titles embedding keywords like "patch" (*Dispatch*) or "mod" (*Modern Combat*) are no longer falsely flagged as updates/mods and skipped when higher version patches exist (`78b5c19`).
- **Crash & reboot recovery:** active streaming installs maintain a liveness marker and create checkpoints at 4 MiB (was 32 MiB), so unexpected shutdowns or reboots can resume without leaving dangling NCM placeholders (`d4dcf84`).
- **UI freeze (ANR) detection:** main loop stall tracking logs the exact contention point when intensive I/O or NSZ decompressor threads block Borealis frame rendering (`9a5189c`).
- **Duplicate task import merge:** re-adding an existing release merges new file selections into the active download task instead of rejecting it (`65c337a`).

### Additional improvements

- **File picker:** dimmed non-.torrent files in directory picker instead of hiding them (`21cb83d`).
- **Catalog updates:** updated catalog manifest delta verification and topic source fallback (`4942432`, `68cae89`).
- **Translations:** added Korean (`ko`) locale and fixed Italian settings mapping (`e53d78f`, `7e6635b`).
