## What's new since 1.6.2

**In short:** a reimagined Web Companion with sidebar navigation, remote library management and diagnostic log tailing; independent catalog channel with offline descriptions; port archive layout editor; NAND installation safety margins, FAT32 split-resume stability, and support for 8 languages.

### Web Companion Redesign & Remote Management

- **Sidebar navigation & layout:** modern, responsive desktop and mobile interface with quick navigation across Downloads, Catalog, Installed library, Add, Diagnostic Logs, and Settings.
- **Live source & storage status:** companion sidebar reflects active download method (Direct BitTorrent vs Debrid provider with credential status), live microSD free space, and mini-queue activity.
- **Remote game library (Installed tab):** inspect games installed on the Switch, check for available updates, and queue update tasks remotely without touching the console.
- **Diagnostic logs & live telemetry:** view a real-time tail of `pipensx.log` filtered by category (Real-Debrid, Install, Errors, Performance) and run installation speed benchmarks directly from the browser.
- **Over-the-air NRO updates:** upload a newly built `pipensx.nro` through the web companion and apply it on the Switch with an authorization PIN modal.
- **Comprehensive localization:** Web Companion translated across 8 languages (English, Russian, Brazilian Portuguese, French, Spanish, Simplified Chinese, Italian, Korean).

### Ports & Extras

- **Remote port layout editor:** configure extraction folders and select which files deploy from multi-file port archives (zip/7z/rar) before downloading.
- **Port & archive guidance modal:** informative guidance dialog for non-PFS0 ports explaining that files are stored in `/switch/pipensx/downloads/` and need extraction to SD root or manual installation.
- **Explicit download-only status:** non-package and download-only tasks clearly report *«Files saved to SD card»* upon completion rather than ambiguous installation status.

### Installation & Stability (P0-1 through P0-4)

- **NAND system memory safety margin:** installations to internal storage (BuiltInUser / NAND) enforce a 512 MB safety buffer (`kNandSafetyMarginBytes`) to prevent Horizon OS storage panics and system crashes on tight EmuNAND partitions.
- **FAT32 resume overwrite resolution:** eliminated overwrite conflicts and fsync failures during debrid split downloads on FAT32 filesystems.
- **Base game title classification:** game titles embedding words like "patch" (*Dispatch*) or "mod" (*Modern Combat*) are no longer falsely flagged as updates/mods and skipped when higher version patches exist.
- **Network buffer exhaustion protection:** graceful recovery on Switch BSD socket `ENOBUFS` errors without connection storms; transient piece buffer allocation limits no longer abort the process.
- **Install rate degradation fix:** fixed install gate rate-EMA collapse where streaming downloads could stall to 0 B/s.
- **Crash & reboot recovery:** active streaming installs checkpoint at 4 MiB (down from 32 MiB) with liveness markers, safely resuming after unexpected reboots.
- **UI stall (ANR) tracking:** main loop contention point is logged when intense I/O or NSZ decompressor threads delay Borealis rendering.
- **Repeated import merge:** re-adding an existing release merges newly selected files into the active download task instead of declining.

### Catalog & Debrid

- **Dedicated pipensx-catalog channel:** manifest-verified catalog release channel (`manifest.json` + `catalog.json`) with hash validation and delta downloads.
- **Offline descriptions (.pdx):** bundled offline descriptions across 8 languages for fast browsing without requiring internet access.
- **Grouped Real-Debrid downloads:** multi-file releases via Real-Debrid are handled as grouped archive transfers with CRC and size validation.
- **Topic source fallback:** catalog player filter fallback and source topic URL metadata preservation.

### Interface & Languages

- **Added Korean (`ko`) locale:** full Switch UI localization in Korean.
- **Italian (`it`) settings fix:** correct mapping of Italian system preferences to `LOCALE_IT`.
- **Dimmed non-.torrent files:** file picker dims unsupported extensions instead of hiding them completely.
